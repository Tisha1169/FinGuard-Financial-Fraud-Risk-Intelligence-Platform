# Screenshots

No static screenshots are committed yet — the live, publicly-accessible
demo at **[fintechgaurd.streamlit.app](https://fintechgaurd.streamlit.app/)**
is the current source of truth for what the dashboard looks like.

When adding screenshots, follow this naming convention so the main
[README.md](../../README.md)'s screenshot table resolves correctly:

| File | Capture |
|---|---|
| `01_executive_overview.png` | Executive Risk Overview tab, full KPI row + charts |
| `02_transaction_intelligence.png` | Transaction table with a CRITICAL-tier transaction expanded |
| `03_alert_queue.png` | Alert & Investigation Queue with the action panel open |
| `04_case_investigation.png` | Customer 360 view for a confirmed-fraud case |
| `05_model_monitoring.png` | Model & Portfolio Monitoring tab, XGBoost vs. Logistic Regression comparison |

Recommended: 1280px-wide PNGs, light theme, captured from the live demo
(not local data, so numbers match what a recruiter sees when clicking
through).
